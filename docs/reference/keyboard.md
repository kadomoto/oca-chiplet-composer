# Keyboard

Everything works from the keyboard. The canvas takes focus with <kbd>Tab</kbd> or the **Skip to the canvas** link.

| Key | Action |
|---|---|
| Arrow keys | move the selected chiplet by 0.5 mm (2 mm with <kbd>Shift</kbd>) |
| <kbd>L</kbd> | turn the link tool on or off |
| <kbd>Delete</kbd> | delete the selection; undo from the notification |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | undo, redo (also <kbd>Ctrl</kbd>+<kbd>Y</kbd>) |
| <kbd>+</kbd>, <kbd>−</kbd>, <kbd>0</kbd> | zoom in, zoom out, fit the substrate |
| <kbd>Esc</kbd> | leave the link tool; close the File menu |
| <kbd>←</kbd> <kbd>→</kbd> on the tabs | move between result tabs |

Without dragging: the inspector's **Objects** list selects chiplets and links, **Add link** connects two chiplets, and X and Y place a chiplet exactly. In the Python editor, <kbd>Tab</kbd> indents; press <kbd>Esc</kbd>, then <kbd>Tab</kbd>, to leave it.
