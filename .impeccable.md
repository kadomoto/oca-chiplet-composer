# Design context

Read by the frontend-design skill before any design work on this project.

## Audience

Chiplet and SoC architects, package engineers, and EDA researchers. They know UCIe, AXI, interposers and bump pitch, and they are evaluating Tenstorrent's OCA Harness. Many will first meet the tool through a shared link or a GIF in the README.

## Use cases

- Sketch a multi-chiplet package early, before any physical design exists.
- See how package choices (organic, interposer, bridge), die placement and link widths move latency, bandwidth, power and cost.
- Check the same configuration against the Harness virtual platform running real firmware, including two-die runs over AXI-over-UCIe.
- Export a bundle to rerun the simulations by hand.

## Brand personality and tone

Industrial and utilitarian, but refined: an engineering instrument, not a marketing page. It borrows from assembly drawings (dimension lines, a title block) and from the real package (solder mask, silicon, gold bumps). Precise, quiet and dense, with one bold element: the package canvas.

## Constraints

- Single HTML file, no build step, works offline (fonts degrade to the system stack).
- WCAG AA contrast, full keyboard operation, light and dark themes, usable down to 390 px.
- Physical colours on the canvas (laminate, silicon, gold, copper) stay the same in both themes.
